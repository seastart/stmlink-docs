examples:
  layout: auto
  watermark_type: 1
  window_tag_type: L

更新应用的默认录制配置。三个字段都是可选的，只传要改的即可。

+ `layout` 取值同「启动录制/合流/直播任务」
+ `watermark_type`：`1` 无水印、`2` 单排、`3` 多排（`0` 表示沿用系统默认）
+ `window_tag_type` 是每个画面上的成员名标签位置，用字母组合表示：`L` 左、`R` 右、`T` 上、`B` 下，可组合如 `LB` 表示左下；**留空表示不显示标签**

改动只影响之后启动的新任务，进行中的任务不受影响。

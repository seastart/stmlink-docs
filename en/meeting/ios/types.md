## Data structures
### SEALogConfig
Log configuration

| **Property** | **Description** |
| --- | --- |
| enableLocalLog | [Meaning] Whether to enable process-wide local log collection<br/>[Recommended value] Default: YES. When enabled, logs are written to a local file and the host app's console output is kept as well. |


### SEAMeetingParam
Meeting parameters

Required when you create or update a room.

| **Property** | **Description** |
| --- | --- |
| roomId | [Meaning] Room ID<br/>[Recommended value] Generated by the cloud<br/>[Note] Don't set this field when you create a room; it's required when you update room information. |
| roomNo | [Meaning] Room number<br/>[Recommended value] Generated by the cloud<br/>[Note] Don't set this field when you create or update room information. |
| title | [Meaning] Meeting title<br/>[Recommended value] Required when you create a room.<br/>[Note] Can be used as the display title of the meeting in lists and elsewhere; UTF-8 encoded. |
| content | [Meaning] Meeting description<br/>[Note] Can be used as the display description of the meeting in lists and elsewhere; UTF-8 encoded. |
| password | [Meaning] Meeting password<br/>[Note] If you set a meeting password when creating the room, users must also provide the matching password to enter the meeting. |
| meetingType | [Meaning] Meeting type<br/>[Recommended value] Default: [SEAMeetingTypeInitiate](#seameetingtype) |
| beginTime | [Meaning] Meeting start time<br/>[Recommended value] Required when the meeting type is `scheduled meeting`.<br/>[Note] Start time as a Unix timestamp |
| endTime | [Meaning] Meeting end time<br/>[Recommended value] Required when the meeting type is `scheduled meeting`.<br/>[Note] End time as a Unix timestamp |
| entryMutePolicy | [Meaning] Mute-on-entry state<br/>[Recommended value] Default: [SEAMeetingMuteState3](#seameetingmutestate) |
| watermarkDisabled | [Meaning] Whether the room watermark is disabled<br/>[Recommended value] Default: YES |
| screenshotDisabled | [Meaning] Whether screenshots are disabled in the room<br/>[Recommended value] Default: NO |
| chatDisabled | [Meaning] Whether chat is disabled in the room<br/>[Recommended value] Default: NO |
| waitingRoomDisabled | [Meaning] Whether the waiting room is disabled<br/>[Recommended value] Default: YES |
| extendInfo | [Meaning] Extended information |


### SEAMeetingEnterParam
Meeting entry parameters

Required when you call `enterRoom:onSuccess:onFailed:()` on `MeetingKitRoom` to enter a meeting.

| **Property** | **Description** |
| --- | --- |
| roomNo | [Meaning] Meeting number<br/>[Recommended value] Usually 9 digits<br/>[Note] When entering, you can use either the **meeting number** or the **meeting ID** to enter the meeting. |
| meetingId | [Meaning] Meeting ID<br/>[Recommended value] Usually an encrypted string<br/>[Note] When entering, you can use either the **meeting number** or the **meeting ID** to enter the meeting. |
| password | [Meaning] Meeting password<br/>[Note] If a meeting password was set when the room was created, you must provide the matching password to enter the meeting. |
| nickname | [Meaning] In-meeting nickname<br/>[Recommended value] Shown as display information in the meeting; UTF-8 encoded. |
| avatar | [Meaning] In-meeting avatar<br/>[Recommended value] Shown as display information in the meeting; UTF-8 encoded. |
| extendInfo | [Meaning] Extended information |
| isAudience | [Type] BOOL<br/>[Meaning] Whether to enter the meeting as audience<br/>[Recommended value] Default: NO. Set it to YES to enter the meeting as audience. |

### SEANetworkQosShakeLevel
Network latency anti-jitter level

| **Constant** | **Value** | **Description** |
| --- | :---: | --- |
| SEANetworkQosShakeLevelUltraShort | `0` | Ultra-short (0): about 120 ms one-way latency. No packet loss compensation in this mode, and B-frames are disabled in encoding. Not recommended for real use |
| SEANetworkQosShakeLevelShort | `1` | Short (1): about 200 ms one-way latency. Single packet loss compensation, 1 B-frame. Usable for two-way talk |
| SEANetworkQosShakeLevelMedium | `2` | Medium (2): about 350 ms one-way latency. Two rounds of packet loss compensation, 1 B-frame. Recommended for two-way talk |
| SEANetworkQosShakeLevelLong | `3` | Long (3): about 600 ms one-way latency. Three rounds of packet loss compensation, 3 B-frames. Only for one-way viewing; not recommended for two-way talk. This parameter can't be set dynamically |

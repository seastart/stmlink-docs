title: "RTCEngineEvent"
description: "API reference for RTCEngineEvent, the Android global error listener passed to RTCEngine.create(...) that shares the Engine lifecycle: onError parameters and an example. Read to handle blocked operations and errors that don't belong to a single channel's events."
---

`RTCEngineEvent` is passed in at `RTCEngine.create(...)` and shares the Engine lifecycle. It carries only Engine-level errors; join results, users, tracks, and channel connection events are still dispatched by the corresponding channel's `RTCClientEvent`.

If you only need to override some methods, extend `RTCEngineSimpleEvent`.

## onError(channelId, errorCode, message)

```kotlin
fun onError(
    channelId: String?,
    errorCode: Int,
    message: String?
)
```

| Parameter | Type | Description |
| --- | --- | --- |
| `channelId` | `String?` | The channel the error belongs to; `null` when it can't be attributed to a specific channel. |
| `errorCode` | `Int` | The raw error code, which may come from librtc, errors generated by the SDK itself, the backend, or the media streaming vendor. |
| `message` | `String?` | Runtime context for the error; `null` when no information is available. |

Example:

```kotlin
val engineEvent = object : RTCEngineSimpleEvent() {
    override fun onError(channelId: String?, errorCode: Int, message: String?) {
        val descriptor = RtcErrorCatalog.find(errorCode)
        Log.e(
            "SRTC",
            "channel=$channelId code=$errorCode name=${descriptor?.name} message=$message"
        )
    }
}
```

The former `RTCClientEvent.onError(...)` and the intermediate wrapper type `RTCEngineError` have been removed. For error code ownership, see [Error codes](/en/rtc/android/error-codes).

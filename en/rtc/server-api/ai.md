## Get meeting minutes

`POST /server/v1/ai/summary/get`

Authentication: required (see [Overview](/en/rtc/server-api/overview))

Get the meeting minutes (Markdown) of a speech recognition session.

+ If the app has automatic minutes enabled, minutes are generated automatically when the session ends; you can also generate them manually with "Generate meeting minutes"
+ Generation is asynchronous: if status is 0 or 1, try again later; when generation completes or finally fails, the channel receives the custom message ai_summary_ready
+ The large language model is configured by the platform operator in the admin console; if none is configured, minutes are not generated

**Request parameters**

<ParamField body="session_id" type="string" required>
  Recognition session ID, from the response of "Start speech recognition" or the session list
</ParamField>


Request example:

```json
{
  "session_id": ""
}
```

**Response parameters**

<ResponseField name="summary_id" type="string">
  Minutes ID
</ResponseField>

<ResponseField name="session_id" type="string">
  Recognition session ID
</ResponseField>

<ResponseField name="channel" type="string">
  Channel name
  Example: `fire`
</ResponseField>

<ResponseField name="template_id" type="string">
  ID of the template used for generation
</ResponseField>

<ResponseField name="status" type="integer">
  Minutes status: 0 queued, 1 generating, 2 completed, 3 failed
</ResponseField>

<ResponseField name="content" type="string">
  Minutes content in Markdown; if regeneration fails, the last successful content is kept
</ResponseField>

<ResponseField name="model" type="string">
  Name of the model used for generation
</ResponseField>

<ResponseField name="prompt_tokens" type="integer">

## Generate meeting minutes

`POST /server/v1/ai/summary/generate`

Authentication: required (see [Overview](/en/rtc/server-api/overview))

Generate (or regenerate) meeting minutes for a speech recognition session. It runs asynchronously and immediately returns the queued minutes.

+ You can regenerate with a different template; until the new result is ready, the last successful minutes are kept
+ Calling again while minutes for the same session are being generated returns an error; wait until it finishes
+ When generation completes or finally fails, the channel receives the custom message ai_summary_ready; you can also poll "Get meeting minutes"

**Request parameters**

<ParamField body="session_id" type="string" required>
  Recognition session ID
</ParamField>

<ParamField body="template_id" type="string">
  Minutes template ID; if omitted, the app's template is used, or the default template if the app hasn't set one
</ParamField>


Request example:

{

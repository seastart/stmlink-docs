title: "GB28181 cameras"
description: "Bring GB28181 cameras and NVRs into meetings: look up platform info and register the device and channels in the admin console, configure platform access on the camera (Hikvision example), and invite channels into the meeting, with screenshots and a field mapping."
---

GB28181 camera integration takes three steps: **the camera registers to the device gateway → register the device and channels in the console → invite channels into the meeting**.
Cameras only send video into the meeting (one-way), and multiple channels under one NVR can each enter as a separate video.

The example below uses a Hikvision camera. All example values correspond across steps; just replace them with your own.

---

## 1. View the platform info

Open the admin console **Device management** → **GB28181** → **Platform info**:

![Platform info](/zh/product/device-access/images/admin-gb-platform-info.png)

These four values must be entered on the camera exactly as shown, so note them down:

| Platform info | Example | Meaning |
| --- | --- | --- |
| SIP server ID | `37070000082000000001` | The device gateway's GB28181 ID |
| SIP server (domain) | `3707000008` | GB28181 domain |
| SIP server address | `192.168.10.5` | Device gateway address; the camera must be able to reach it |
| SIP server port | `5070` | GB28181 signaling port |

With multiple device gateways, each gateway has its own set; use the set for the gateway the camera registers to.

---

## 2. Register the device in the console

On the **GB28181** tab, click **Add device**:

![Add a GB28181 device](/zh/product/device-access/images/admin-gb-add.png)

| Field | What to enter |
| --- | --- |
| Device name | Any name you like, for example "East gate PTZ camera" |
| Device id | The camera's GB28181 ID (20 digits). If it doesn't have one, click **Auto-generate** and enter the generated ID on the camera |
| Device password | The password the camera uses to register; must match on both sides |
| Device gateway | Which gateway the camera registers to |

---

## 3. Configure platform access on the camera

Log in to the camera's web management page. On Hikvision it's under **Configuration → Network → Advanced Settings → Platform Access**. Set the platform access mode to **28181**, enable it, and enter:

![Hikvision camera platform access settings](/zh/product/device-access/images/gb-hik-platform.png)

| Field on the camera | What to enter | Source |
| --- | --- | --- |
| Protocol version | GB/T28181-2016 | — |
| SIP server ID | `37070000082000000001` | Step 1 "Platform info" |
| SIP server domain | `3707000008` | Step 1 "Platform info" |
| SIP server address | `192.168.10.5` | Step 1 "Platform info" |
| SIP server port | `5070` | Step 1 "Platform info" |
| SIP username, SIP user authentication ID | `37070000082008000001` | "Device id" from step 2 |
| Password | Same as "Device password" in step 2 | Step 2 |
| Heartbeat interval | **30 seconds** | Too long and the device is judged offline |

After saving, the camera's **Registration status** changes to "Online", and the status in the console's device list also changes to **Online**:

![GB28181 device list](/zh/product/device-access/images/admin-gb-list.png)

<Warning>
**We recommend a 30-second heartbeat interval.** Device defaults are often longer; if the platform doesn't receive a heartbeat in time, it marks the device offline and invitations fail.
</Warning>

---

## 4. Register channels

A device can have multiple video channels (each camera on an NVR, each stream of a PTZ camera), and **the unit that enters the meeting is the GB28181 channel**.

First find the channel encoding on the camera: further down the same page under **Encoding ID → Video Channel Encoding ID**, note the channel's encoding:

![Hikvision camera video channel encoding ID](/zh/product/device-access/images/gb-hik-channel.png)

Back in the console, click **+** to the left of the device to expand it, then click **Add channel**:

![Add a channel](/zh/product/device-access/images/admin-gb-channel-add.png)

| Field | What to enter |
| --- | --- |
| Channel name | The name shown in the meeting, for example "East gate PTZ camera - channel 1" |
| Channel id | The camera's "Video Channel Encoding ID" |

The result after adding:

![Channel list under the device](/zh/product/device-access/images/admin-gb-channel-list.png)

---

## 5. Invite into the meeting

GB28181 cameras can't dial in by themselves; only the platform can invite them:

+ **Admin console**: meeting details → **Invite** → **Invite device** → **GB28181**
+ **Meeting client**: the host clicks **Invite** → **Invite device**
+ **Business system**: call [Invite devices to the channel](/en/rtc/server-api/agent#invite-devices-to-the-channel); each GB28181 channel is one invitation

Once in the meeting, the video is a member of the meeting, named by the channel name.

### PTZ and preset positions

Panning, zooming, and recalling preset positions are currently **done through the server API** (the admin console doesn't have buttons for them yet):
[Control GB28181 device PTZ](/en/rtc/server-api/agent#control-gb28181-device-ptz-direction-and-zoom) and [Manage GB28181 device preset positions](/en/rtc/server-api/agent#manage-gb28181-device-preset-positions).

## Field mapping quick reference

```text
Camera                              Admin console
─────────────────────────────────   ─────────────────────────
SIP server ID / domain / address / port  ←  Platform info
SIP username / authentication ID     =   Device id
Password                             =   Device password
Video Channel Encoding ID            =   Channel id
```

Can't connect? See the [FAQ](/en/product/device-access/faq#gb28181-camera-wont-connect).

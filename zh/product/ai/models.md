字幕、翻译、纪要、同传、语音客服用到的模型，都在管理后台 **AI 能力 → AI 服务与方案** 里配置，不写在配置文件里。
页面有两个页签：

+ **AI 服务**：登记一个个具体的模型服务——地址、模型名、密钥
+ **AI 方案**：把服务组合起来——每种语言用哪个识别服务、用哪个大模型、哪个语音合成和音色

应用在 **AI 能力 → 应用 AI 设置** 里选用一个方案，不选就用默认方案。每次点「保存」立即生效，不用重启服务。

## AI 服务

点「新增服务」，按**类别**登记：

| 类别 | 用在哪 | 接入方式 |
| --- | --- | --- |
| 语音识别 | 字幕、转写、同传、语音客服 | FunASR（websocket） |
| 大模型 | 实时翻译、纪要、同传、语音客服 | OpenAI 兼容大模型 |
| 语音合成 | 同传译音、语音客服 | 通用 HTTP TTS（请求体模板）、OpenAI 兼容 TTS |
| 实时语音 | — | 预留，暂未接入 |

### 一键模板

选「一键模板」会自动填好接入方式、地址格式和参数，只需再改地址、密钥、模型名：

| 模板 | 类别 | 说明 |
| --- | --- | --- |
| FunASR 中文 2pass | 语音识别 | 边说边出 + 整句定稿，支持热词 |
| FunASR 英文（offline） | 语音识别 | 只出整句；自动做英文结果清洗；不发热词 |
| OpenAI 兼容大模型 / DeepSeek | 大模型 | 填地址、模型名、密钥 |
| 风远离线 TTS | 语音合成 | 我方提供的离线语音合成镜像，见下文「内置开源模型」 |
| IndexTTS | 语音合成 | 对接 HTTP 接口返回 base64 音频的 IndexTTS 服务 |
| OpenAI 兼容 TTS | 语音合成 | `/v1/audio/speech` 接口 |

### 支持的接入方式

**大模型：OpenAI 兼容接口。** 凡提供 `/chat/completions` 接口的都能接，如 DeepSeek、通义千问（兼容模式）、
私有部署的 vLLM / Ollama。要点：

+ **模型名必须写对**：部分服务对填错的模型名不报错，而是悄悄换成默认模型
+ **密钥可以不填**：客户内网的大模型服务常常没有鉴权，留空即可
+ **思考模式**：可选「开启 / 关闭 / 不发送」。翻译、语音客服对速度敏感，建议关闭；不认识这个参数的服务选「不发送」
+ 可设超时、并发上限、采样温度、输出上限

**语音识别：FunASR（websocket）。** 填 `ws://` 或 `wss://` 地址，识别模式选 **2pass**（实时中间结果 + 整句定稿，中文用）
或 **offline**（只出整句，英文用）。

**语音合成：两种方式。**

+ **通用 HTTP TTS（请求体模板）**：客户已有的合成服务大多是「POST 一段 JSON、返回音频」，按它的接口填一份请求体模板即可接入，
  不用我方改代码。模板里可用 `{{text}}`（文字）、`{{voice}}`（音色）、`{{lang}}`（语言）、`{{speed}}`（语速）；
  返回方式可选「直接返回音频」或「JSON 里的 base64」，音频格式 wav 或 pcm
+ **OpenAI 兼容 TTS**：`/v1/audio/speech` 接口，返回 wav

### 测试与试听

每个服务都可以点「测试」：

| 类别 | 测试做什么 |
| --- | --- |
| 大模型 | 发一句话（默认「请回复 OK」），显示耗时和模型的原话；出错时显示服务端返回的原始错误 |
| 语音合成 | 合成一句话并**在页面上试听**，显示音频时长和采样率；可换音色、语速 |
| 语音识别 | 上传一段 wav 样音，看识别结果 |

### 密钥的安全

+ 密钥（API Key，以及 HTTP TTS 的额外请求头里的每个值）**加密存储**，页面和接口只返回打码后的值（如 `sk-****abcd`）
+ 编辑服务时密钥留空表示不修改；要删掉已存的密钥用「清空」
+ **改了服务地址，原密钥不会沿用**，必须重新填写，防止把旧密钥发往新地址
+ 操作日志里的密钥字段一律打码；给大模型的提示词和模型输出默认不写进服务日志

## AI 方案

方案就是「一套 AI 服务的组合」，点「新增方案」后分三块填写：

| 区块 | 字段 | 说明 |
| --- | --- | --- |
| 选用服务 | 语音识别 | **按说话语言**各选一个识别服务，如中文选「FunASR 中文」、英文选「FunASR 英文」。「其它语言（\*）」兜底；没配的语言不识别 |
| | 大模型 | 翻译、纪要、语音客服共用 |
| | 语音合成 | 同传与语音客服共用 |
| 语音合成与同传 | 音色 | **按语言**选音色；没配时用语音合成服务的默认音色 |
| | 语速 | 1 为正常语速 |
| | 同传原声音量 | 播译音时说话人原声压到的音量，0～1，默认 0.2；0 = 静音 |
| 语音客服 | 提示词、开场白 | 见 [AI 语音客服](/zh/product/ai/voice-agent#内置-ai-语音客服) |

+ 可以建多个方案，其中一个设为**默认方案**；应用没选方案时用它
+ 例如不同部门用不同的大模型，就建两个方案，分别给各自的应用选上
+ 有应用在用的方案不能删除或改名
+ 两人同时编辑时，后保存的人会被提示「配置已被他人修改」，刷新后再改，不会互相覆盖
+ 现场排障可以用「编辑 JSON」直接改整份配置

## 内置开源模型

为了能**完全离线**部署，语音识别和语音合成有我方准备好的离线镜像，模型随镜像提供，CPU 即可运行。**大模型不内置**，用客户自己的。

| 用途 | 模型 | 许可证 |
| --- | --- | --- |
| 中文语音识别 | FunASR：Paraformer-large 中文识别（2pass：流式 + 整句高精度）、FSMN 端点检测、CT-Transformer 实时标点、Ngram 语言模型（热词依赖它） | FunASR 模型开源许可协议（要求注明来源与作者、保留模型名称） |
| 中文数字规整 | FunASR 服务配套的中文逆文本规整（「一百二十」→「120」） | 以模型发布方的许可为准 |
| 英文语音识别 | FunASR：Paraformer-large 英文离线识别（vocab10020） | FunASR 模型开源许可协议 |
| 英文语音合成 | Piper `en_US-ljspeech-medium`（英文女声） | 模型 MIT；训练数据 LJ Speech 为公有领域 |
| 中文语音合成 | MeloTTS `vits-melo-tts-zh_en`（中文女声，可中英混读） | MIT |

<Note>
许可证信息根据各模型官方发布页整理，**以模型官方的最新许可为准**。离线语音合成的推理框架为 sherpa-onnx（Apache-2.0）。
选型时刻意避开了训练数据仅限非商用的声音模型。
</Note>

客户已有更好的模型（如 GPU 上的 IndexTTS、更大的识别模型）时，按上文的接入方式登记成服务、在方案里换掉即可，平台其它部分不用改。
各服务的资源占用见 [部署与资源规划](/zh/product/ai/deploy)。

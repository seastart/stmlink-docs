会中开启转写后，每个开麦的人说的话都会实时变成文字：网页会议里显示成字幕，会后可以查看整场的转写原文，
也是[会议纪要](/zh/product/ai/summary)和[同声传译](/zh/product/ai/interpretation)的基础。

---

## 能做什么

| 能力 | 说明 |
| --- | --- |
| **按说话人转写** | 每个开麦人的声音单独识别，每句话都带说话人的 ID 和名字，不需要再做声纹区分 |
| **会中字幕** | 中文边说边出（先出中间结果，一句说完再修正为定稿）；英文一句说完后整句出 |
| **实时翻译字幕** | 每句定稿后由大模型翻译成指定语言，译文与原文一起显示 |
| **热词** | 按应用配置专有名词（公司名、产品名、人名），提高识别命中率 |
| **转写原文存档** | 定稿句按「场次」存档，会后可在会议客户端、管理后台或服务端接口查看 |

---

## 谁来开、在哪开

+ **会议里**：主持人在网页会议的「字幕与转写」面板打开「会议转写」，所有成员随即看到字幕；每个人还可以在本机关掉「显示字幕」，不影响别人。要翻译时在开启转写前选好「实时翻译」的语言
+ **业务系统**：服务端调用[启动语音识别](/zh/rtc/server-api/asr)接口，对一个频道开启转写
+ **管理后台**：**AI 能力 → 应用 AI 设置** 里配置热词、实时翻译；**纪要记录** 里查看各场次的转写原文

转写的单位是**场次**：一个频道从开启到销毁算一场。会中关掉转写再打开，仍然是同一场，转写原文接着记，最后只出一份纪要。

## 支持的语言

| 语言 | 字幕效果 | 说明 |
| --- | --- | --- |
| 中文 | 边说边出，一句说完后修正为定稿 | 默认语言；支持热词 |
| 英文 | 一句说完后整句出，没有中间结果 | 实测句尾停顿后约 0.8 秒出定稿；英文模型不支持热词 |

+ 说话人用哪种语言识别，由 [AI 方案](/zh/product/ai/models#ai-方案)里「语音识别」按语言选的服务决定；没有配置的语言不会被识别
+ 只用中文的会议不需要做任何语言设置。中英都有的会议，成员在同声传译里设置「我的语言」后，按各自的语言识别
+ **中英夹杂的人建议按中文识别**：中文模型能识别夹杂的英文单词（准确率会下降），英文模型基本识别不了中文

## 实时翻译字幕

在「应用 AI 设置」里打开**实时翻译**并选目标语言（如英语），或者开启转写时指定目标语言，之后每句定稿都会翻译一份：

+ 翻译不阻塞原文：原文字幕照常先出，译文随后到（实测定稿到译文约 1 秒，取决于大模型速度）
+ 大模型并发满了时这句**直接跳过**不翻，宁缺勿拖，避免译文越积越晚
+ 需要在 AI 方案里配好大模型

实时翻译只出**一种**目标语言的文字。需要「每人听自己的语言」，用[同声传译](/zh/product/ai/interpretation)。

---

## 热词

识别不准的专有名词（如公司名、产品型号）可以加成热词：**AI 能力 → 应用 AI 设置 → 热词**，每条填词和权重（建议 1～100，越大越优先命中）。

+ 热词按应用生效，开启转写时下发给识别服务，整场沿用；改了热词要下一次开启转写才生效
+ 应用没配热词时用平台默认热词；部署时还可以在识别服务上配一份全局热词，对所有应用生效
+ 英文识别模型不支持热词

## 会后查看转写原文

| 在哪看 | 怎么看 |
| --- | --- |
| 网页会议客户端 | 历史会议的纪要页里有「转写原文」页签 |
| 管理后台 | **AI 能力 → 纪要记录**，查看纪要时切到「转写原文」 |
| 会议 Web SDK | `aiTranscript()` 按场次返回整场句子，见 [SMeeting · aiTranscript](/zh/meeting/web/api-reference/SMeeting) |
| 服务端接口 | [语音识别场次列表、句子列表](/zh/rtc/server-api/asr) |

每句带说话人、开始和结束时间（相对场次开始）；开了实时翻译的还带译文。

## 各端怎么拿到字幕

| 用法 | 做法 |
| --- | --- |
| 网页会议客户端 | 现成的字幕浮层和转写开关，不用开发 |
| SMeeting 会议 SDK（Web） | 事件 `ASR_RESULT`（原文）、`ASR_TRANSLATION`（译文），见 [SMeeting Web 接口](/zh/meeting/web/api-reference/SMeeting) |
| SRTC 音视频 SDK（各端） | 识别结果以频道自定义消息 `asr_res`、译文以 `asr_trans` 下发，各端收频道自定义消息即可自己显示 |

<Note>
会议 SDK 里现成的字幕、纪要、转写原文接口目前只在 **Web 端**提供；其它端可以按 SRTC 频道消息自行显示字幕。
</Note>

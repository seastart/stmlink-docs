> 本页根据 `rtc-android` 仓库 `master` 主干的版本配置和提交记录整理，不包含独立分支的更新。可通过 `RTCEngine.version()` 获取当前 SDK 版本。

### [2.0.23] - 2026.07.27
#### 优化
+ 引入远端音频订阅声明式对账器 `SubscribeReconciler`，将同一轨道的订阅和退订操作串行化，避免高频会控事件导致状态不一致；
+ 流媒体重连后按最终订阅意图自动恢复远端音频订阅，并为订阅失败提供最多 3 次的有界退避重试；
+ 用户离开频道或频道释放时自动清理订阅对账状态。

### [2.0.22] - 2026.07.23
#### 新增
+ 新增远端视频帧全量落盘能力，便于问题排查；
#### 优化
+ 新增 `armeabi-v7a` ABI 支持并优化构建配置。

### [2.0.21] - 2026.07.22
#### 优化
+ 简化网络质量变化回调：每条质量报告均触发回调，并新增 `STABLE` 趋势状态；
+ 为信令数据通道消息补充序列化字段注解，避免混淆后解析失败。

### [2.0.19] - 2026.07.22
#### 新增
+ 新增本地音频临时静音接口 `enableLocalAudio`。

### [2.0.18] - 2026.07.22
#### 修复
+ 修正 Camera2 帧旋转角度计算，使其与 WebRTC 语义一致；
+ 默认启用前置摄像头镜像，改善设备旋转时的本地预览体验。

### [2.0.17] - 2026.07.20
#### 新增
+ 新增网络质量跨档变化回调。

### [2.0.16] - 2026.07.15
#### 新增
+ 支持频道内用户身份变更，以及观众升降级处理。

### [2.0.15] - 2026.07.04
#### 修复
+ 优化资源释放流程，修复并发场景下可能发生的崩溃。

### [2.0.14] - 2026.07.03
#### 优化
+ 优化音频能量回调，兼容特定音频轨道 ID。

### [2.0.13] - 2026.07.03
#### 修复
+ 修复 WebRTC m-line 复用导致订阅端 `track.id` 冻结、流识别错误的问题；
+ 修复远端视频 View 复用时画面旋转角度异常的问题。
#### 优化
+ 重构摄像头采集与推流状态机，支持音频推流的声明式对账；
+ 优化 YUV 帧处理和展讯（sprd）编码器兼容性。

### [2.0.11] - 2026.06.17
#### 新增
+ `LocalCameraTrack` 新增前置摄像头镜像控制能力。

### [2.0.10] - 2026.06.15
#### 新增
+ 支持网宿通用流订阅。

### [2.0.9] - 2026.05.20
#### 新增
+ 适配 SRTC SFU 26.4：支持服务端媒体质量数据、活跃说话人、订阅候选层及画质自动降级字段；
+ 新增摄像头能力与设备列表查询、按 `cameraId` 选择摄像头、摄像头角度偏移和热插拔事件；
+ 摄像头采集切换为原生 Camera2 实现，并优化帧转换性能与内存使用。

### [2.0.8] - 2026.05.09
#### 新增
+ 重构网宿流媒体引擎，支持发布附加流。

### [2.0.7] - 2026.04.21
#### 优化
+ 优化 Ook 流媒体引擎的大流、小流分辨率、帧率和码率配置。

### [2.0.6-alpha.9] - 2026.03.09
#### 新增
+ 支持 FyStreamEngine 和 WsStreamEngine 的自定义视频流输入与发布；
+ 支持自定义流和屏幕共享流使用 1080p、10 fps 参数；
+ Android 14 及以上前台服务增加麦克风类型权限支持。
#### 变更
+ `RTCClientEvent.onChannelNotStarted` 更名为 `onError`；
+ `LocalCustomVideoTrack.inputData` 改为接收基础帧数据，由 SDK 负责组装。

### [2.0.6-alpha.8] - 2025.11.19
#### 修复
+ 修复 SFU 连接断开后无法重连、订阅时 `ignore` 处理异常等问题；
+ 升级 VCS SDK，移除底层 MQTT 自身重连机制以规避崩溃。

### [2.0.6-alpha.7] - 2025.11.14
#### 新增
+ 自定义消息回调新增 `sid` 和 `nickName` 字段。
#### 修复
+ 修复部分 HarmonyOS 3.0 及以下设备发送视频时出现绿条的问题。

### [2.0.6-alpha.5] - 2025.10.24
#### 修复
+ 修复流媒体重连时 `OptionInfo` 信息缺失、远端设备断开后无法重新连接等问题。

### [2.0.6-alpha.2] - 2025.10.13
#### 变更
+ 订阅远端流以 `trackId` 作为主要标识，新增 `getUserTrackInfoByTrackId`；
+ 远端成员离开时由 SDK 自动取消订阅，无需应用层额外处理。
#### 修复
+ 修复 WebRTC 发布时 SDP 持续膨胀、远端音频订阅失败及流操作时序异常的问题。

### [2.0.6-alpha.1] - 2025.09.26
#### 新增
+ 新增音频能量、媒体质量和扬声器控制回调；
+ 支持自定义编码参数和会议外预览的摄像头、屏幕共享能力。
#### 修复
+ 修复订阅响应 SDP 或 offer 为空时的异常；
+ 优化 YUV 帧转换，兼容 stride。

### [2.0.5] - 2025.09.09
#### 修复
+ 修复屏幕录制服务找不到、停止共享回调缺失和混淆配置问题。

### [2.0.4] - 2025.09.04
#### 新增
+ 统一 Ook 与网宿媒体统计数据回调，补充丢包率计算和音量柱能力。

### [2.0.2-alpha.2] - 2025.08.18
#### 新增
+ `PublishCustomOptions` 支持控制是否发布小流。
#### 修复
+ 升级 WebRTC SDK，缓解 HarmonyOS 设备编码器异常导致的卡顿；
+ 修复断网重连后已发布、已订阅轨道无法恢复及横竖屏画面角度异常的问题。

### [2.0.1] - 2025.05.23
#### 变更
+ 重构 RTC SDK 层，解耦流媒体能力并支持切换流媒体引擎；
+ 引入 WebRTC 与 SFU 流媒体框架，支持摄像头采集、发布、订阅和资源释放。

### [2.0.0-34] - 2025.04.27
#### 新增
+ 支持保存 H.264 文件，音视频文件统一存储至 `audioVideo` 目录。

### [2.0.0-33] - 2025.04.23
#### 新增
+ 新增 1080P、720P、480P、180P 内置摄像头预设。

### [2.0.0-32] - 2025.03.25
#### 新增
+ `onJoinSucceed` 回调新增 SDK 版本号参数。
#### 修复
+ 更新底层库并修复文件存储位置、日志模块重新初始化等问题。

### [2.0.0-31] - 2025.01.24
#### 新增
+ 新增语音转写功能开关。
#### 修复
+ 修复屏幕共享断网重连崩溃、取消订阅状态错误和 IM 连接异常等问题。

### [2.0.0-30] - 2024.12.22
#### 变更
+ 用户离开频道回调直接提供 `UserInfo`。

### [2.0.0-29] - 2024.10.24
#### 变更
+ 轨道新增、更新、移除事件不再过滤当前用户。

### [2.0.0-28] - 2024.10.17
#### 优化
+ 成员被订阅尚未发布的流时，补充明确日志提示。

### [2.0.0-27] - 2024.10.11
#### 新增
+ 新增即时通讯能力；
#### 变更
+ 底层库适配 MQTT SSL 连接，移除 `RTCClientOptions` 中的 `netid` 和 `sgid` 配置。

### [2.0.0-26] - 2024.09.20
#### 优化
+ 优化即时通讯断连原因及简单事件回调。

### [2.0.0-25] - 2024.09.20
#### 新增
+ 增加即时通讯基础能力与应用层测试用例。

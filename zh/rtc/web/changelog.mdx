### v0.7.0 - 2026-09-30

<Warning>
**本版是破坏性变更**：错误码全面重排、SDK 报错文案改为英文，并新增 `language` 参数。凡是按 `code` 的数值（尤其是 `106000`）、按中文报错文案、或按浏览器原始异常做判断的代码，升级后都需要按下表调整。完整码表见 [错误码](/zh/rtc/web/error-codes) 与 [错误码规则与总表](/zh/rtc/error-codes)。
</Warning>

#### 破坏性变更
+ **错误码全面重排**：SDK 自身的报错按跨端统一码表分配低 3 位码，不再大多落在 `106000`。请按 `code` / `baseCode` 判断，不要按文案判断
+ **报错文案改为英文**：SDK 自身报错的 `message` / `msg` 全部改为英文，只给开发者和日志看；给终端用户的提示请按错误码自行映射（错误码页有「建议给用户的提示」列）
+ `SdkError` 改为继承 `Error`（有 `message`、`name`、`stack`，`e instanceof Error` 成立，`msg` 保留兼容）；新增 `baseCode`（低 3 位语义码）；包里导出 `SdkError` 与 `ErrorCode`
+ HTTP 非 200 / 网络请求失败统一抛 `SdkError(106006)`，HTTP 状态放在 `message` 里（原为不带码的 `Error`，如 `"500:..."`）
+ 采集失败（`startCapture`、请求设备权限）由浏览器原始异常改为带码的 `SdkError`：`name` 与 `message` 保留浏览器原值（如 `NotAllowedError`），原始异常在 `cause`，按 `e.name` 判断的存量代码照常生效
+ 接口 HTTP 200 但响应体没有 `code` 字段时，以前按服务端业务错误处理（心跳直接离开频道），现在视为响应解析失败 `106011`、继续重试；响应体不是 JSON 同为 `106011`
+ 已离开（或正在离开）的频道上调用 `publishLocalTrack`、`subscribeRemote*` 抛 `106001`（`Channel has been left`）；`unpublishLocalTrack` / `unsubscribeRemoteTrack` 离开频道后仍静默成功

#### 新增
+ 初始化参数 **`language`**（如 `zh-CN`、`en`；不传则跟随 `navigator.language`，取不到为 `zh`）：SDK 请求服务端时带 `Accept-Language`，**服务端业务错误（`1000`–`99999`）的文案随之返回中文或英文**。SDK 自身的报错固定为英文，不受它影响。见 [类型定义 · SdkInitParams](/zh/rtc/web/types#sdkinitparams)
+ 自动播放被拦截时的提示框内置中 / 英两套文案（按 `language` 选择），可用初始化参数 `autoPlayDialogText` 覆盖；`disableAutoPlayDialog` 行为不变

#### 修复
+ 自动播放提示框不再拼接轨道 desc、改用纯文本构建，修复远端 desc 可注入 HTML 的问题

#### 变更
+ 轨道 `toString()` 前缀改为类名风格（如 `LocalCameraTrack[...]`），日志中的轨道名随之变为英文；连接质量评估 `QualityEvaluation.reasons` 改为英文（用于诊断，不是契约）
+ npm 页面说明改为中英双语，许可证改为专有（UNLICENSED）

#### 旧码 → 新码对照

| 场景 | 0.6.x 及以前 | 0.7.0 |
| --- | --- | --- |
| 不在频道内 / Token 已过期 / 流轨道不存在 | `106001` / `106002` / `106003` | 不变（文案改英文） |
| 其它 SDK 自身的报错（参数非法、状态不允许、发布描述冲突、未采集就发布、超过发布 / 订阅上限、浏览器不支持等） | `106000` | 按场景的独立码，见 [错误码](/zh/rtc/web/error-codes) |
| HTTP 非 200 / 网络请求失败 | 不带码的 `Error` | `106006` |
| 响应不是 JSON / 缺 `code` 字段 | 原始解析异常 / 当作服务端错误 | `106011` |
| 摄像头 / 麦克风权限被拒 | 浏览器 `NotAllowedError` | `106231` / `106251`（`name` 仍为 `NotAllowedError`） |
| 屏幕共享被取消或未授权 | 浏览器 `NotAllowedError` | `106039` |
| 设备不存在或已拔出 | 浏览器 `NotFoundError` / `OverconstrainedError` | `106021` |
| 设备被占用 / 硬件错误 | 浏览器 `NotReadableError` 等 | `106018` |
| 流媒体引擎重连中发布 | `106014` | `106014`（不变） |
| 流媒体引擎未连接 / 已断开（不在重连中）时发布、订阅 | `106014` | `106300` / `106301` |
| 发布 / 订阅的媒体连接进入 failed / closed | 字符串「发布失败」「订阅失败」 | `106015` |
| CDN 引擎发布 / 订阅协商超时 | 字符串「发布超时」「订阅超时」 | `106302` / `106303` |
| 加入频道时媒体连接超时 | 不带码的 `Error` | `106007` |
| 服务端业务错误（`1000`–`99999`） | 原样透传 | 原样透传，文案随 `language` 返回中文或英文 |

### v0.6.3 - 2026-09-23

+ fix: 本地混音改为直连 AudioContext 出声，修复 Web 端接收音频发钝
+ fix: 混音内部用于激活远端轨的隐藏音频元素补上静音并保留引用，避免被回收后混音偶发无声
+ feat: RemoteAudioTrack 补齐 setJitterBufferTarget / getJitterBufferTarget（此前仅视频轨支持）

### v0.6.2 - 2026-09-02

+ fix(channel): 同一 desc 重复发布直接抛错，堵住关不掉的幽灵轨

+ fix: 业务错误不再被吞成「调用被取消」，重连遇容量不足可自愈

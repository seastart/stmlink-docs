### v0.3.0 - 2026-09-30

<Warning>
**本版是破坏性变更**：会议层错误码重排、SDK 报错文案改为英文，并新增 `language` 参数。凡是按 `code` 的数值（尤其是 `206000`）或按中文报错文案做判断的代码，升级后都需要按下表调整。完整码表见 [错误码](/zh/meeting/web/error-codes) 与 [错误码规则与总表](/zh/meeting/error-codes)。底层 SRTC 同步升级到 Web 0.7.0，它透传上来的 `106xxx` 也已重排，见 [SRTC Web 更新日志 · v0.7.0](/zh/rtc/web/changelog)。
</Warning>

#### 破坏性变更
+ **会议层错误码重排**：按跨端统一码表分配低 3 位码，不再落在 `206000`。请按 `code` 判断，不要按文案判断
+ **报错文案改为英文**：SDK 自身报错的 `message` / `msg` 全部改为英文，只给开发者和日志看；给终端用户的提示请按错误码自行映射（错误码页有「建议给用户的提示」列）
+ 请求会议服务端的网络失败 / HTTP 非 200 统一为 `206007`，HTTP 状态放在 `message` 里；响应无法解析或缺 `code` 字段为 `206356`
+ 采集 / 权限错误原样透传 SRTC 层的码（如 `106231` 无摄像头权限、`106251` 无麦克风权限、`106039` 屏幕共享被拒），打开失败时的清理步骤不再覆盖原始错误
+ `McuTaskStatus` 取值与服务端对齐：新增 `WaitStart = 0`、`WaitEnd = 2`，`Exception` 由 2 改为 3、`Normal` 由 3 改为 4。按成员名比较的代码升级后即可得到正确语义，**直接写数字 2 / 3 判断的代码需自查**

#### 新增
+ 初始化参数 **`language`**（如 `zh-CN`、`en`；不传则跟随 `navigator.language`，取不到为 `zh`），会同时设置底层 SRTC：请求会议服务端和 SRTC 服务端时都带 `Accept-Language`，**服务端业务错误（`1000`–`99999`）的文案随之返回中文或英文**。SDK 自身的报错固定为英文，不受它影响。见 [类型定义](/zh/meeting/web/types)
+ 初始化参数 `autoPlayDialogText`：覆盖自动播放提示框的文案（默认按 `language` 显示中文或英文）
+ 包里导出 `SdkError` 与 `MeetingErrorCode`（会议层低 3 位）。SRTC 包也导出同名的 `SdkError`，两个包同时引入时请起别名

#### 修复
+ `McuRecordDetail` 类型与服务端实际返回对齐：补齐 `began_at` / `total_duration` / `records` 等字段，`mcu_at` / `mcu_dur` 标记为废弃（服务端仍回填，新接入请改用 `began_at` / `total_duration`）

#### 变更
+ 依赖的 SRTC 升级到 `@seastart/srtc-web-sdk` 0.7.0
+ npm 页面说明改为中英双语，许可证改为专有（UNLICENSED）

#### 旧码 → 新码对照

| 场景 | 0.2.0 及以前 | 0.3.0 |
| --- | --- | --- |
| 未登录 / Token 已过期 / 不在会议中 / 无权限（主持人操作） | `206001` / `206002` / `206003` / `206004` | 不变（文案改英文） |
| 房间已禁止打开摄像头 / 麦克风 / 共享 | `206000` | `206004` |
| Token 无法解析 | 原始解析异常 | `206005` |
| 已在会议中，重复进入 | `206000` | `206006` |
| 请求会议服务端网络失败 / HTTP 非 200 | 不带码的 `Error` | `206007` |
| 会议中没有该成员 | `206000` | `206010` |
| 摄像头 / 麦克风 / 共享已开启时重复开启、尚未开启时切换设备等 | `206000` | `206011` |
| 响应无法解析 / 缺 `code` 字段 | 原始解析异常 / 当作服务端错误 | `206356` |
| 采集 / 权限 / 推拉流失败（SRTC 层透传） | SRTC 旧码或浏览器原始异常 | SRTC 新码，如 `106231`、`106251`、`106039`，见 [SRTC Web 更新日志](/zh/rtc/web/changelog) |
| 服务端业务错误（`1000`–`99999`） | 原样透传 | 原样透传，文案随 `language` 返回中文或英文 |

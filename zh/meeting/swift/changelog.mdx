### [1.1.0] - 2026.08.02
#### 变更
+ 依赖`SRTC`升级至`1.1.0`，随之带来公开 API 上不再出现底层 WebRTC 类型等变化，详见音视频 SDK 的更新日志。

### [1.0.0] - 2026.08.02
#### 新增
+ 首个正式版本，以预编译 XCFramework 形式通过 Swift Package Manager 分发，包含 iOS 真机、iOS 模拟器、macOS 三个平台切片；
+ SDK 主入口类为`SMeetingEngine`。
